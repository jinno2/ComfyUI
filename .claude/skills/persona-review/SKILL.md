# ComfyUI ペルソナレビュー

対象読者は、ローカルで生成ワークフローを使う人と、この fork を保守する人。
他リポのマーケティング用ペルソナは流用しない。

## 固有ペルソナ

1. **ローカル生成ワークフロー利用者**: 動く設定と障害の影響範囲を知りたい。
   古い注意書き、誤った修正案、実機で確認したか分からない説明を指摘する。
2. **デバイス・回帰テスト保守者**: dtype/device、モデル互換性、テストの実際の保証範囲を確認する。
   モックと実機の混同、根拠のない性能評価、追跡できないソース参照を指摘する。

## 手順

- 要求の原文、成果物、該当コードとテストを直接照合する。
- 各視点の反応と指摘（最大2件、なければ「なし」）を記録し、有用な修正を適用する。
- 実施者と方法を明記する。同一エージェントの視点別自己レビューを独立レビューと呼ばない。
- 結果と各指摘の処置、検証コマンド・結果・未検証範囲を既存の `docs/llm-wiki/log.md` に残す。
- 全視点が指摘なしなら、レビュー完了と扱わず、対象と検証の不足を再確認する。
- この手順は外部送信や公開の権限を追加しない。
